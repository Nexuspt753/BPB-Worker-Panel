# :material-fingerprint:{ .md .middle } برنامه‌های پشتیبانی‌شده

در این قسمت می‌تونید حداقل نسخه مورد نیاز برای اتصال بدون مشکل به کانفیگای BPB رو ببینید و همچنین آخرین نسخه پایدار برنامه‌ها رو دانلود کنید.

تعداد دیگه‌ای از برنامه‌ها هم هستن که خیلی خوبن ولی یا دیر به دیر بروزرسانی میشن یا فرمت کانفیگاشون با فرمت استاندارد هسته‌ها متفاوته و اینجا قید نشدن.

## افزودن اشتراک با یک کلیک

در صفحه‌های اشتراک، برای هر برنامه یک دکمه **افزودن با یک کلیک** وجود داره. پنل سیستم‌عامل دستگاه شما رو تشخیص می‌ده و وقتی برنامه روی همون سیستم‌عامل وجود داشته باشه، اشتراک رو با یک لمس به برنامه می‌ده — یا با لینک عمیق (deep link)، یا برای خانواده WireGuard با دانلود آرشیو کانفیگ (بعد از باز کردن آرشیو، یکی از فایل‌های `.conf` رو با برنامه باز کنید).

اگر برنامه روی سیستم‌عامل شما وجود نداشته باشه، دکمه فقط لینک اشتراک رو کپی می‌کنه و مشخص می‌کنه برنامه روی چه سیستم‌عامل‌هایی در دسترسه؛ بنابراین هیچ‌وقت لینکی باز نمی‌شه که دستگاه شما نتونه ازش استفاده کنه.

چند برنامه ممکنه روی یک URL scheme مشترک باشن (مثلاً `clashmeta`، `v2rayng` و `sing-box` رو Hiddify هم ثبت کرده). اگه چند تا از این برنامه‌ها نصب باشن، سیستم‌عامل ممکنه برنامه‌ی دیگه‌ای رو باز کنه — اون برنامه هم می‌تونه همین اشتراک رو وارد کنه و لینک قبلاً کپی شده.

سیستم‌عامل دستگاه از روی user agent تشخیص داده می‌شه؛ iPadOS حتی در حالت مرور دسکتاپ هم به‌عنوان iPadOS شناخته می‌شه، نه macOS.

راهنما:

- **لینک عمیق** — با یک لمس، برنامه باز می‌شه و اشتراک وارد می‌شه.
- **کپی** — برنامه روی این سیستم‌عامل اجرا می‌شه ولی لینکی برای باز کردن نداره، پس لینک اشتراک کپی می‌شه تا داخل برنامه وارد کنید.
- **فایل** — لینک عمیقی وجود نداره؛ آرشیو ZIP شامل فایل‌های کانفیگ دانلود می‌شه؛ بعد از باز کردن، یکی از فایل‌های `.conf` رو با برنامه باز کنید (خانواده WireGuard).
- **—** — نسخه‌ای از برنامه برای این سیستم‌عامل وجود نداره؛ دکمه لینک رو کپی می‌کنه و مشخص می‌کنه برنامه روی چه سیستم‌عامل‌هایی در دسترسه.
