# :material-cog-outline:{ .md .middle } تنظیمات مشترک یا Common

این بخش شامل تنظیماتی میشه که بین همه پروتکل‌ها، پنل، لینک‌های اشتراک و قسمت DNS over HTTPS مشترک هستن.

## Local DNS

این DNS بیشتر برای مقاصد مسیریابی استفاده میشه و به‌صورت پیش‌فرض، سرور Local DNS از Google DNS استفاده می‌کنه.

سرورهای DNS زیادی به‌صورت IP برای Local DNS در دسترسن، ولی می‌تونید از **localhost** استفاده کنید که از سرور DNS اپراتورتون استفاده می‌کنه و برای مسیریابی مناسبه.

## DNS ضد تحریم

این سرور DNS برای [قوانین مسیریابی تحریم‌ها](./routing-rules.md) استفاده می‌شه. سرور DNS پیش‌فرض [Shecan](https://shecan.ir/) هست. قبل از تنظیم قوانین مسیریابی، باید بررسی کنید که آیا این DNS از دامنه‌های مورد نظر شما پشتیبانی می‌کنه یا نه.

!!! info "راهنمایی"
    سرور DNS می‌تونه به شکل IP (UDP DNS)، TCP DNS، DOT یا DoH باشه.

## Fake DNS

می‌تونید Fake DNS رو فعال کنید تا تأخیر DNS کمتر بشه، ولی با احتیاط — ممکنه با بعضی برنامه‌ها سازگار نباشه یا با DNS سیستم تداخل ایجاد کنه. اگه از کارکردش مطمئن نیستید، فعالش نکنید.

## فعال‌سازی IPv6

پنل به‌صورت پیش‌فرض برای پروتکل‌های VLESS و Trojan کانفیگ‌های IPv6 ارائه می‌ده. اگه اپراتورتون از IPv6 پشتیبانی نمی‌کنه، غیرفعالش کنید تا تعداد کانفیگ‌ها کم بشه و همچنین تنظیمات DNS و مسیریابی برای همه پروتکل‌های VLESS، Trojan و Warp بهینه بشن.

## Allow connections from LAN

اگر این ویژگی رو فعال کنید، دیگران در شبکه شما (به عنوان مثال شبکه Wifi) می‌تونن با داشتن IP محلی دستگاه شما از پروکسی شما استفاده کنن. در اصل میتونن یه پروکسی socks روی دستگاه خودشون تنظیم کنن، IP محلی شما رو به عنوان آدرس و این پورت‌ها رو بر اساس برنامه‌ای که استفاده می‌کنید تنظیم کنن:

- v2ray: 10808
- sing-box: 2080
- Clash: 7890

لطفاً توجه داشته باشید که استفاده از این قابلیت در شبکه‌های اداری یا عمومی می‌تونه خطرناک باشه.

## Log Level

سطح گزارش‌های برنامه رو مشخص می‌کنه. بصورت پیشفرض "warning" هست که برای اشکال‌زدایی مشکلات کافیه، با این حال ممکنه لازم باشه برای ثبت issue در Github یا بررسی دقیق فعالیت پروکسی تغییرش بدید.

## دامنه شخصی

اگر دامنه شخصی روی اکانت کلادفلرتون دارید می‌تونید یه زیردامنه دلخواه ازش رو اینجا وارد کنید، به هیچ تنظیماتی در پنل هم نیاز نداره.

کانفیگ‌های مربوط به این دامنه به همون لینک‌های اشتراکتون با نشانه `D` اضافه می‌شه.

## سرور DoH زیرساختی

پنل یه DNS over HTTPS به شما میده که بصورت پیشفرض از DoH رسمی کلادفلر استفاده می‌کنه.

شما از این قسمت می‌تونید اون DoH رو عوض کنید و مثلا از یه سروری مثل Adguard استفاده کنید که تبلیغات و بدافزار و ... رو هم مسدود کنید.

## مسیر پنل و لینک‌های اشتراک

برای جلوگیری از دسترسی بات‌ها یا خزنده‌ها یک مسیر امن برای دسترسی به پنل و لینکای اشتراک دارید، از این قسمت می‌تونید تغییرش بدید.

بعد از تغییر پنل شما رو به آدرس جدید پنل هدایت می‌کنه و باید لینکای اشتراک رو از اول بگیرید.

## دامنه پوششی یا Fallback

بصورت پیشفرض درخواست‌های نامعتبر به ورکر شما پاسخ 404 برمی‌گردونن.

می‌تونید این رفتار رو تغییر بدید و یه دامنه شناخته شده اینجا قرار بدید. فقط دقت کنید بعضی از آدرس‌ها درخواستای ورکر رو محدود کردن، بنابراین باید تست کنید.

## اسم کانفیگ‌ها

به‌صورت پیش‌فرض اسم هر کانفیگی که ساخته میشه بر اساس نوع آدرس و پورتش ساخته میشه. اگه اسم‌های توصیفی‌تری می‌خواید، از این بخش می‌تونید یه **قالب اسم** دلخواه تعریف کنید که برای هر کانفیگ به‌صورت خودکار از روی اطلاعات جغرافیایی (کشور، شهر، استان، ارائه‌دهنده سرویس و نوع اتصال) و اسم‌های دلخواهی که خودتون تعیین می‌کنید پر بشه.

قالب پیش‌فرض به این شکله:

```
{MARKER}{FLAG}{COUNTRY}{CITY} - {IP} - {IPNAME}
```

می‌تونید قالب رو به هر ترکیبی از متغیرهای زیر تغییر بدید.

کادر قالب هم فهرست پیشنهادی دارد: با زدن `{` لیست باز می‌شود، با ادامهی تایپ فیلتر می‌شود و با کلیدهای بالا/پایین و Enter یا Tab می‌توانید یک مورد را درج کنید. فهرست فقط وقتی نمایش داده می‌شود که مکان‌نما داخل یک `{...}` باز است.

!!! info "راهنمایی"
    هر متغیری که مقدارش مشخص نباشه به صورت `--` نمایش داده می‌شه، بنابراین شکل قالب همیشه ثابت می‌مونه حتی وقتی اطلاعات جغرافیایی در دسترس نباشه.

### متغیرهای قابل استفاده

- `{MARKER}` — پیشوند نوع کانفیگ (شامل `F ` برای فرگمنت، `D ` برای دامنه شخصی و `C ` برای CDN سفارشی)؛ وقتی هیچ‌کدوم اعمال نشده باشه خالیه.
- `{FLAG}` — ایموجی پرچم کشور.
- `{COUNTRY}` — اسم کشور.
- `{CITY}` — اسم شهر.
- `{REGION}` — اسم منطقه یا استان.
- `{ISP}` — ارائه‌دهنده خدمات اینترنت.
- `{ASN}` — شماره AS.
- `{TYPE}` — نوع اتصال: `Hosting` یا `Mobile` یا `Residential`.
- `{LATENCY}` — تأخیر به میلی‌ثانیه؛ با تست خودکار اختیاری زیر (یا تست دستی از صفحه Proxy IP) تازه می‌مونه، و وقتی مقدار اندازه‌گیری‌شده‌ای وجود نداشته باشه `--` نشون می‌ده.
- `{IP}` — آدرس کانفیگ.
- `{IPNAME}` — اسم دلخواهی که برای آدرس تعیین کردید (در ادامه توضیح داده می‌شه).
- `{B}` — اسم برند پنل.
- `{F}` — همون پرچم کشوره (نسخه قدیمی).
- `{D}` — آدرس یا دامنه (نسخه قدیمی).
- `{C}` — اسم کشور (نسخه قدیمی).
- `{index}` — شماره ایندکس کانفیگ.
- `{port}` — شماره پورت کانفیگ.

!!! tip "نکته"
    ایموجی `{FLAG}` از کد دو حرفی کشوری که از جستجوی جغرافیایی برمی‌گرده ساخته می‌شه. متغیرهایی مثل `{index}` و `{port}` که به اطلاعات جغرافیایی نیاز ندارن بدون جستجو هم همیشه مقدار می‌گیرن.

### اسم دلخواه برای هر IP

اگه بخواید به یه IP مشخص یه اسم ثابت بدید، هر خط از کادر **Clean IPs** یا فقط خود آدرسِ host هست یا به شکل `host # Name` — بخش بعد از اولین `#` اسم اون کانفیگه که به عنوان `{IPNAME}` نمایش داده می‌شه. برای مثال:

```
1.2.3.4 # سرور من
1.1.1.1 # Cloudflare
1.0.0.1
```

هر کانفیگی که آدرسش با یه خط بالا مطابقت داشته باشه، به جای `{IPNAME}` از اون اسم استفاده می‌کنه. آدرس‌ها دقیقاً همونطوری که نوشته شدن مطابقت داده می‌شن (براکت‌های IPv6 حذف می‌شن). یه خط مثل `1.2.3.4 #` که اسمش خالیه فقط همون آدرسِ خالی از اسم رو اضافه می‌کنه.

### تست خودکار تأخیر

`{LATENCY}` با یه **تست خودکار** اختیاری — یه چک‌باکس در بخش اسم کانفیگ‌ها که به‌صورت پیش‌فرض خاموشه — تازه می‌مونه. وقتی فعال بشه، پنل به‌صورت دوره‌ای آدرس‌های کانفیگ رو با بازه زمانی که انتخاب می‌کنید (۱۰ تا ۱۴۴۰ دقیقه) دوباره اندازه می‌گیره تا `{LATENCY}` نتایج اخیر رو نشون بده. وقتی خاموش باشه، `{LATENCY}` مقدار `--` نشون می‌ده مگر اینکه از صفحه Proxy IP تست دستی بگیرید. توجه کنید این کار مقدار کمی درخواست از ورکر مصرف می‌کنه.

تأخیر از سمت Worker اندازه گرفته می‌شود — همان تست دسترسی که صفحه Proxy IP استفاده می‌کند — پس سرعت رسیدن به آدرس را نشان می‌دهد، نه تأخیر محلی شما.
